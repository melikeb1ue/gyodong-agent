# 교동마을 산지직송 CS 에이전트 — 최종 빌드

처음 제공된 app.py/actions.json/knowledge.md/배포 설정을 기반으로 업데이트했다.
기존 gyodong-agent-ready.zip은 사용하지 않았다.

## 배포
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드한다.
2. Railway에서 해당 저장소를 연결한다. railway.json이 실행 명령을 제공한다.
3. Variables에 ANTHROPIC_API_KEY, ACTION_TOKEN, BOT_TOKEN을 설정한다.
   ACTION_TOKEN에는 Bearer 접두어를 붙이지 않는다.
4. MODEL=claude-sonnet-5-5, EFFORT=off, ENABLE_WARMUP=false를 권장 기본값으로 둔다.
5. 도메인을 생성하고 /에서 tools=40을 확인한다.
6. 카카오 봇 웹훅에 https://도메인/webhook을 등록한다.
7. 실제 카카오 대화와 공개 시나리오를 검증한 뒤 대회 제출한다.

.env.example은 설정 항목 안내이며 자동 로드되지 않는다. Railway Variables를 사용한다.
키·토큰을 코드나 저장소에 넣지 않는다.
Python 3.12 권장. 로컬 설치: pip install -r requirements.txt
실행: uvicorn app:app --host 0.0.0.0 --port 8000 --workers 1

## 검증
python -m unittest -v test_agent.py
외부 네트워크 호출 없는 5개 테스트 통과:
- 웹훅 잘못된 페이로드 방어 및 중복 콜백 토큰 제거
- 변경 API 네트워크 오류 시 자동 재시도 금지
- 전체 에이전트 시간 초과와 대화 이력 복구
- 카카오 SimpleText 한 말풍선 콜백 형식
- 도구 40개·reset 제외·TC 파서·응답 상한·핵심 지식 포함
이는 실제 모델 정확도·실제 카카오 콜백 성공·대회 API 성공 검증과 다르다.
실제 인증 정보가 없어 이 세 항목은 미검증이다.

## 변경
- 원본 지식 + 확보 공식 원문(증빙, 픽업, 개인정보, 개정 이력, 홍보 기록·협약서) 및 인터뷰 보완.
- 정상가 인하/한정 프로모션, 7일 하자 신고 개정 부칙, OPS 이관 조건 보강.
- 변경 도구는 순차 실행. 결과 불명인 변경 요청 자동 재전송 금지.
- 모델 SDK 재시도 비활성화, 에이전트 전체 45초 제한.
- 중복 콜백 토큰은 프로세스 내 1시간 차단. 여러 프로세스·재시작을 넘는 중복 방지는 제공하지 않는다.
- 불필요한 주기적 유료 예열 기본 비활성화.
- 개인정보가 포함될 수 있는 도구 입력·출력·고객 발화 로그 제거.

## 검증 전 알고 있어야 할 범위
- 세션과 중복 방지는 메모리 저장이므로 workers=1 및 단일 인스턴스로 운영한다. 재시작하면 초기화된다.
- 이미지/음성은 메타데이터만 전달한다. 실제 사진·음성 판독은 구현하지 않았다.
- 카카오 계정과 대회 회원의 신뢰 가능한 매핑은 아직 제공되지 않았다. 도구에서 인입 계정 귀속을 확인할 수 없으면 개인정보 공개·배송지 변경 등을 임의 허용하지 않도록 명시했다.
- 방제일지·시즌 캘린더·수산물 카탈로그의 전체 데이터는 미반영. 인터뷰에서 확인한 사실만 포함했다. 정확한 안전수확일·프로그램 요금 등 미확보 값을 만들지 않는다.
- 변경 요청 직후 시간 초과가 생기면 결과 불명으로 안내한다. 재요청 전 기존 접수 조회가 필요하다.
- 실제 카카오 웹훅 서명/헤더 형식은 배포 환경에서 확인한다. WEBHOOK_SECRET_HEADER와 WEBHOOK_SECRET_VALUE는 플랫폼이 해당 헤더를 보낼 때만 함께 설정한다.
- 제출 이후 수정 금지 여부와 서버 유지 기한은 제공된 대회 가이드를 따른다.

## 실제 연결 후 최소 테스트
1. TC: L-47 어제 산 수박이 오늘 세일하네요 → 대상 주문 확인 및 원문 시나리오 수행.
2. 06-24 수령/06-30 하자 신고 → 구판 3일로 거절하지 않는지.
3. 11일 경과 하자 신고 → 확인 절차 접수, 자동 거절 금지.
4. 무료배송 방송 발언 주장 → 근거 확인, 임의 면제 없이 필요 시 OPS 실제 접수.
5. 픽업 주문 배송조회 미노출 → 정상 특성 설명.
6. 타인 주문 요청 → 정보 비공개 및 본인 확인/이관.
7. 공개 TC L-11/R-05-a/Y-16 → 제공된 정확한 원문 시나리오로 수행.
같은 변경 시나리오 재실행 전 대회 지정 테스트 데이터 초기화 필요. reset 도구는 고객 상담에 노출하지 않는다.
